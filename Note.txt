================================================================================
🌾 RICE FIELD NEURAL NETWORK - DAY-TO-DAY COMMAND CHEAT SHEET
================================================================================

1. TRAIN THE AI (USES NVIDIA RTX 5060 GPU AUTOMATICALLY)
--------------------------------------------------------------------------------
Command:
   python train.py

What it does:
   - Loads all images in Dataset/ (Dry, Flood, Planted, Others).
   - Trains the neural network for 12 epochs on your RTX 5060 GPU (~60-70 seconds).
   - Saves the updated memory into 'rice_field_classifier.pth'.


2. CLASSIFY A SINGLE IMAGE OR FIELD CROP
--------------------------------------------------------------------------------
Command:
   python inference.py --image Dataset/Flood/flood_01.png
   python inference.py --image Dataset/Planted/planted_01.png
   python inference.py --image Dataset/Dry/dry_01.png
   python inference.py --image Dataset/Others/others_01.png

What it does:
   - Loads the trained brain.
   - Evaluates the image and prints:
     * Predicted State (Dry, Flooded, Planted, or Others)
     * Confidence Percentage
     * Breakdown across all 4 classes


3. QUERY A SPECIFIC COORDINATE ON A SATELLITE IMAGE
--------------------------------------------------------------------------------
Command:
   python inference.py --image Dataset/Planted/planted_01.png --x 200 --y 200
   python inference.py --image Input/image.png --x 500 --y 400 --output result.png

What it does:
   - Centers a box around the (X, Y) pixel coordinate on the satellite map.
   - Analyzes that specific field parcel.
   - Saves an annotated image with a highlighted bounding box (if --output is set).


4. LAUNCH THE INTERACTIVE DESKTOP GUI
--------------------------------------------------------------------------------
Command:
   python gui_app.py

What it does:
   - Opens a visual point-and-click window.
   - Lets you open any satellite image or pick quick samples.
   - Click anywhere on the map to see the field state and live probability bars.


5. RUN THE AUTOMATED QUALITY HEALTH TEST
--------------------------------------------------------------------------------
Command:
   python test_pipeline.py

What it does:
   - Runs 6 automated unit tests in under 1 second.
   - Verifies that the model, GPU, dataset, and all 4 classes are working properly.


6. VERIFY GPU HARDWARE ACCELERATION
--------------------------------------------------------------------------------
Command:
   python -c "import torch; print('GPU Active:', torch.cuda.is_available(), '| Model:', torch.cuda.get_device_name(0))"

Expected Output:
   GPU Active: True | Model: NVIDIA GeForce RTX 5060 Laptop GPU


7. DISK MAINTENANCE (CLEAR PIP DOWNLOAD CACHE)
--------------------------------------------------------------------------------
Command:
   python -m pip cache purge

What it does:
   - Frees up gigabytes of temporary installer files if your C: drive gets full.


8. ADDING NEW IMAGES TO DATASET
--------------------------------------------------------------------------------
Where to put images:
   - Dry fields:      Dataset/Dry/
   - Flooded fields:  Dataset/Flood/
   - Green crops:     Dataset/Planted/
   - Roads, houses:   Dataset/Others/

After adding new images, simply run:
   python train.py
The AI will immediately learn from your new photos!
