DIRECTORY STRUCTURE AT A GLANCE:
--------------------------------------------------------------------------------
• Input/           -> Incoming raw pictures placed here for AI analysis & web classification.
• Unsorted/        -> Staging pool of pictures loaded into GUI Curator for manual sorting.
• Dataset/         -> Ground-truth dataset divided into 7 classes used to train the neural network.
                      (Dry, Water, Wet, Green rice, Green weed, Straw, Others)
• parcel_pictures/ -> Clean JPEG files of flagged parcels referenced by 'farm_parcels.db'.


1. LAUNCH THE WEB PARCEL DATABASE & CURATION DASHBOARD
--------------------------------------------------------------------------------
Command:
   python web_server.py
   # Or on a custom port: python web_server.py 8000

What it does:
   - Starts the web dashboard server on http://localhost:5000 (or custom port).
   - Lazy Database Initialization: 'farm_parcels.db' is NOT created until you click 'Classify Input Directory'.
   - Scans images in Input/ recursively, classifies them into the 7 states, and stores parcels with GPS coordinate as Primary Key.
   - PICTURE RETENTION RULES:
     * If 'Green rice' (or 'Planted') OR Low Confidence (<80%):
       Sets flag = 1 and saves clean JPEG image into 'parcel_pictures/' with relative path stored in DB.
     * Otherwise ('Dry', 'Water', 'Wet', 'Green weed', 'Straw', 'Others' with high confidence):
       Sets flag = 0 and picture_path = NULL (discards picture to save disk space).
     * If coordinate already exists, UPSERTS (updates) the existing record rather than creating a duplicate.
   - Operator Review Modal:
     * View saved parcel pictures directly from 'parcel_pictures/'.
     * Confirm / Overrule Category:
       - If confirmed as 'Green rice' (or 'Planted'): retains picture in 'parcel_pictures/' and keeps flag = 1.
       - If changed to non-green classes ('Dry', 'Water', 'Wet', etc.): clears flag (flag = 0), permanently deletes the image file from disk, and sets picture_path = NULL.


2. LAUNCH THE DESKTOP DATASET CURATOR & TRAINING MANAGER
--------------------------------------------------------------------------------
Command:
   python gui_app.py

What it does:
   - Dual-pool curation tool: Unsorted Pool (Unsorted/) vs Sorted Dataset (Dataset/).
   - 7-Class Keyboard Shortcuts:
     [1]     -> Move to Dry
     [2]     -> Move to Water
     [3]     -> Move to Wet
     [4]     -> Move to Green rice
     [5]     -> Move to Green weed
     [6]     -> Move to Straw
     [7]     -> Move to Others
     [U]     -> Return image to Unsorted Pool
     [Space] -> Accept AI Suggestion
     [↑ / ↓] -> Navigate through images
     [Del]   -> Delete image
   - Auto-Advances selection immediately after moving for rapid sorting.
   - Fix Mis-sorts: Select any sorted image in 'All Sorted' view and press 1-7 to move it to the right class folder on disk.
   - One-Click Retraining: Click "🚀 Train AI Model" to retrain in the background with live progress tracking.


3. TRAIN THE NEURAL NETWORK BRAIN (RTX 5060 GPU ACCELERATED)
--------------------------------------------------------------------------------
Command:
   python train.py

What it does:
   - Loads all training images across the 7 classes in Dataset/:
     (Dry, Water, Wet, Green rice, Green weed, Straw, Others).
   - Trains for 25 epochs using CUDA GPU acceleration with random augmentations (crops, flips, rotations, color jitter).
   - Automatically adapts backbone weights and head if expanding classes.
   - Saves optimized checkpoint weights to 'rice_field_classifier.pth'.


4. BATCH CLASSIFY IMAGES & EXPORT CSV REPORTS
--------------------------------------------------------------------------------
Command:
   # Classify all images in Input/
   python inference.py

   # Classify a single specific image
   python inference.py --image path/to/image.jpg

   # Classify a custom directory and export to CSV
   python inference.py --dir Input --csv classification_summary.csv

What it does:
   - Recursively scans target directory and subdirectories for supported images.
   - Extracts EXIF GPS coordinates from every image.
   - Predicts 7-class probabilities and confidence scores.
   - Prints summary breakdown table to console and optionally writes full results to CSV.


5. EMBED REALISTIC CAMBODIA GPS COORDINATES & CONVERT PNGs
--------------------------------------------------------------------------------
Command:
   # Embed GPS coordinates into a directory (keeps existing formats)
   python embed_coordinates.py Input
   python embed_coordinates.py Dataset
   python embed_coordinates.py path/to/image.jpg

   # Optional: Convert PNG images to JPG before embedding GPS
   python embed_coordinates.py png Input
   python embed_coordinates.py Input --convert-png

What it does:
   - Generates realistic farmland GPS coordinates across Cambodia's major rice provinces:
     (Battambang, Takeo, Prey Veng, Siem Reap, Pursat, Kampong Cham, Banteay Meanchey, Kandal).
   - Writes standard EXIF GPS tags directly into image metadata.
   - With 'png' / '--convert-png' flag: Converts any PNG image to clean JPEG (handling transparency on white background), embeds GPS coordinates, and removes the original PNG file.


6. RUN THE AUTOMATED TEST SUITES
--------------------------------------------------------------------------------
Command:
   python -m unittest discover -s tests
   # Or run individual test suites:
   # python -m unittest tests/test_pipeline.py
   # python -m unittest tests/test_parcel_db.py

What it does:
   - Runs all 11 unit tests across two test suites:
     * test_pipeline.py (7 tests): Verifies 7-class model forward pass shape, individual field predictions, recursive Input/ folder scanning, and operator overrule continuous dataset export.
     * test_parcel_db.py (4 tests): Verifies lazy SQLite database creation, coordinate Primary Key upserts, directory storage for parcel pictures, operator review deletion rules, and legacy BLOB-to-disk migration.
